# Otium 0.1.4

- **Pause works from the tray when only sharing is on.** The tray menu and the dashboard decided "earning" from
  the processor and graphics card alone, so a computer that only shared its internet showed "Start earning" while it
  shared, and couldn't be paused from there. Both now follow the main switch, and the tray's label updates when you
  press Pause or Start elsewhere.
- **Otium's 2% now applies to AIOZ.** AIOZ sharing used to carry no Otium fee. From this version Otium keeps 2% of
  what your AIOZ node earns, the same share as mining and Proxybase sharing: it stays in the node and goes to Otium's
  own address in separate withdrawals, never through your payouts. AIOZ earned before this version
  stays fee-free, and the earnings shown in Otium are already without Otium's share. Mysterium still has no Otium fee.
