# Otium 0.1.4

- **Pause works from the tray when only sharing is on.** The tray menu and the dashboard decided "earning" from
  the processor and graphics card alone, so a computer that only shared its internet showed "Start earning" while it
  shared, and couldn't be paused from there. Both now follow the main switch, and the tray's label updates when you
  press Pause or Start elsewhere.
