# Otium 0.1.9

- **Graphics cards that looked "stalled" now mine.** SRBMiner holds its output back when another program reads it, so on cards that print only a line every few seconds (an RX 580, a Quadro P600) Otium saw nothing for three minutes and set the coin aside with "no hashing for 3 minutes", though the miner was running fine. Otium now reads the miner's log file, which is written as it goes, and removes it afterwards.
