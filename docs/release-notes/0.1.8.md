# Otium 0.1.8

- **The problem-report button on Home names the real problem.** When one device was waiting and the other was in an error, the button showed the waiting device's line. It now shows the failing device's own message.
- **Problem reports show how the graphics miner started and stopped.** Each report lists the last few launches (which coin, how many cards, the miner file's size) and stops (still running or exited with which code, and how many lines it printed), so a miner that prints nothing at all can be looked into.
- **Internet sharing earnings are shown as a range per day.** Proxybase isn't paying at its quoted 1–5 GB a day right now, so the website and the app show a low-to-high estimate (about $0.50 to $1.50 a day in the US, from Proxybase's listed per-GB rates) instead of one figure. Your real pace replaces it after the first hour.
