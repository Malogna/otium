# Otium 0.1.7

- **A close-to-payout notification.** When your balance at the pool reaches four fifths of its payout threshold, Otium tells you once, and again for the next payout after this one is sent. It says whether the pool pays by itself or whether Auto pay is off for your address.
- **Fans stay quiet while Otium switches slices.** Otium's short fee slices and new pool routes restart the graphics card's miner within seconds, and each restart used to hand the fans back to the card's own fan curve for a moment (up to 93% on an RTX 3080). Held fans now stay held for 45 seconds after the miner stops, and go back to the card only if it doesn't start again.
- **A one-off miner stop is no longer reported as a problem.** A miner that Windows ended at shutdown or logoff, or that antivirus closed once, showed as a computer with an error in Otium's dashboard. An error is now reported only when it goes on for five minutes.
- **Problem reports say how much graphics memory is free**, and which coins never started and why, so a small card that can't mine is easier to understand.
